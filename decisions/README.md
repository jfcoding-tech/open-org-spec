# Decisions — open-org-spec

Architectural decision records for the open-org-spec standard.

## Convention

One file per decision, named `YYYY-MM-DD-short-title.md`. Entries are dated by decision date, not file-creation date. Each ADR carries a `**Status:**` field (`Proposed | Accepted | Superseded by <link>`) and a short body covering Context, Decision, and Consequences.

ADRs here are normative: they shape how the standard evolves and how adopters interact with it. Decisions that affect only one adopter belong in that adopter's own `decisions/` folder (e.g., `<adopter>/governance/decisions/`), not here.
